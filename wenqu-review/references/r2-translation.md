# R2：翻译腔审查

本标准已可独立使用。与 **wenqu-translate** 的 `references/translation-guide.md` 是同一套判断标准：那份是翻译时的自查清单，这份是翻译完成后立即执行的独立审查（wenqu-translate 强制触发，不等全文写完）。两者不重复执行同一步骤，但共享标准。

## 执行步骤

逐段读文章，重点查三类欧化语言：

| 欧化类型 | 典型信号 | 判断方法 |
|---------|---------|---------|
| **介词结构直译** | 通过...来...、对...进行...、基于...的 | 去掉介词短语，中文意思还完整吗？完整 → 介词多余 |
| **名词化动词** | "进行压缩"、"实现了...的功能" | 直接用动词："压缩"；删掉"实现了...的" |
| **被动语态过度** | "被...所决定"、"由...来完成" | 改主动："X 决定"、"X 完成" |

## 额外检查项

- **直译英文技术词**：如"记忆预取"（prefetch 直译，带硬件术语味道）→ 改"后台记忆检索"
- **直译英文结构**：如"两条异步旁支"（async side branch 直译）→ 改"两条异步分支"
- **文学化词汇错位**：如"后面才不会迷失"（技术场景里过于文学化）→ 改"后面才不会绕"
- **英文动词名词化**：如"高效清桌"→ 改"快速完成上下文压缩"
- **用"送给模型"描述 API 调用**：如"送给模型看的历史消息"→ 改"模型调用的输入消息"
- **引号强调已有描述**（冗余引号）：如`准备好"这一轮的历史消息"`→ 去掉引号，直接陈述

## 报告格式

问题句全文 + 行号 + 2-3 个候选改法，候选之间说明语感差异。
