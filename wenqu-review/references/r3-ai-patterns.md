# R3：模式化与空泛表达

参考：`language/humanizer-zh.md`。

R3 不把某个词、三项并列、加粗标签或固定句式本身视为 AI 痕迹。它只检查：这些表达是否用形式掩盖信息不足，或让文章陷入可预测的模板节奏。

## 检查方法

先按段落判断信息是否推进，再看是否存在重复模式。不要一搜到触发词就机械替换。

### 1. 空泛收束

段落结尾看似总结，却没有给出新的事实、判断、边界或下一步关系。

**判断方法：** 删除这句话后，读者是否少了能据此行动或理解机制的信息？没有的，报告为空泛风险。

### 2. 形式性重复

相邻句、相邻段或相邻小节换词复述同一结论，既不增加条件，也不推进因果或范围。

**判断方法：** 能否合并为一句，而不损失独立信息？能的，报告为重复。

### 3. 模板化节奏

连续多节使用同一种开头、排比、转折或收束，读者可以预先猜到下一句的结构，削弱论述本身。

**判断方法：** 是内容需要同样的结构，还是只是套用了同一种写作模板？只有后者才报告问题。

### 4. 伪结构化

用长列表、连续加粗标签、三段式或“不是 A 而是 B”制造完整感，但各项没有独立信息，或彼此关系未说明。

**判断方法：** 每一项能否回答不同的问题、提供不同的信息？能的保留；不能的合并、删减或改为正常段落。

## 不应误判的情况

- 三项并列确实覆盖三种不同情况；
- `**标签：**` 帮助读者快速定位独立的判断；
- “不仅……而且……”表达了真实的递进或对比；
- 结论句准确收束了前文复杂讨论，并补足了读者需要记住的判断。

## 与其他审查项的边界

| 问题 | 归属 |
|------|------|
| 句子拗口、关系难跟、指代不清 | R5 连贯性与清晰度 |
| 英文语序、直译搭配 | R2 翻译腔 |
| 章节重复、形式选择不当 | R4 结构自检 |
| 题材与表达方式不匹配 | R6 文体与叙事契合 |
| 形式很多但没有增加信息，或模板化重复削弱内容 | R3 模式化与空泛表达 |

## 报告格式

- **空泛收束：** 位置、当前表达没有新增什么信息、删除或具体化方向。
- **形式性重复：** 两处位置 + 重复的判断 + 合并或保留差异的建议。
- **模板化节奏：** 连续出现的位置 + 重复模式 + 仅调整哪几处即可打破单调。
- **伪结构化：** 当前形式 + 各项缺少的独立信息 + 应合并、拆分还是补充关系。

未发现问题时，确认：`R3 模式化与空泛表达 clean。`
