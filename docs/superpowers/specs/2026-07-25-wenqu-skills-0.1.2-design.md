# wenqu-skills 0.1.2 设计

## 目标

将一次长篇技术文章写作中反复暴露的通用问题，补进既有的写作、审查与配图流程。此次只完善现有流程，不新增独立技能或改变用户入口，因此版本为 `0.1.2`。

## 七项补强

1. **句子来源标识：** 在素材库与 R0 中区分实现事实、团队选择、外部研究、合理推断、简化场景；不同来源使用不同的证据与表述要求。
2. **指令优先级：** 在 wenqu-write 明确当前用户指令、已确认本轮计划、文章级偏好、写作画像、通用规则的覆盖顺序；冲突时停止并说明。
3. **骨架—正文偏离检查：** 在 R4 与写作收尾自检中确认正文仍回答确认过的问题、没有扩大范围、没有写丢已承诺的机制或边界。
4. **评测叙事与指标可比性：** 在 R0 和素材模板中检查评测对象、条件、口径、比较边界及结论外推范围。
5. **修改授权分级：** 在修改流程中区分可直接修复、可按确认计划执行、必须先讨论、必须重新确认骨架的四类操作。
6. **文章生命周期状态：** 为单篇文章增加轻量状态文件，记录素材、骨架、章节、图片、审查与发布是否完成，作为跨会话续写的唯一进度入口。
7. **完成条件核对标准：** 为章节、图片、修改轮次和全文定义完成条件，并在写作收尾、R4、R7 和发布前使用。

## 归属与边界

| 能力 | 落点 | 不做什么 |
| --- | --- | --- |
| 来源、评测可信度 | `wenqu-review` R0、`materials.md` 模板 | 不把外部材料自动视为实现事实 |
| 意图、授权、进度、验收 | `wenqu-write` 工作流与文章状态模板 | 不将某篇文章的领域术语升为通用规则 |
| 骨架偏离、验收 | `wenqu-review` R4 / R7 | 不以格式指标代替内容判断 |
| 图文闭环 | 既有 R7 / `wenqu-image` 流程引用状态 | 不改变已确定的 HTTPS 图片版本历史规则 |

## 数据与流程

- 单篇文章新增 `references/status.md`，模板为 `references/planning/wenqu-status.md`：仅记录状态、下一步和待复查项；不复制素材、骨架或 changelog 内容。
- `materials.md` 增加“来源类型”和“评测设计”字段；新建素材或出现评测结论时填写。
- 修改开始前按授权分级决定直接执行、按计划执行，或先讨论、更新骨架；实质变更仍使用已有 `change-impact.md`。
- 写作收尾按完成条件核对标准检查；完整审查继续以 `R0 → R5 → R1 → R2 → R3 → R4 → R6 → R7` 为顺序。
