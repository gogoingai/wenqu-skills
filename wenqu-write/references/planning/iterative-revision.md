# 已有长文的分章修改

仅在用户修改已有长文、且本轮涉及不止一句措辞时读取。本文件不替代骨架；它约束的是已确认结构下的迭代节奏。

## 先拆任务

按章节或明确子节拆分本轮任务。每个任务只记录：

- **范围**：本次改哪一节，不改哪些相邻内容；
- **目标**：读者读完这节应理解什么；
- **依据**：要重读的正文段落和直接相关素材；
- **形式**：需要调整的段落、列表、表格或图片说明。

用户没有要求全文统一调整时，不把局部反馈扩展为其他章节的改写。

## 每节执行

1. 动手前读取目标章节的当前文本，与已确认的改动方案比对。
2. 重读直接相关素材；需要补充技术性结论时，先核实再写。
3. 只完成当前任务，并检查本节是否仍与上下文、术语和图表一致。
4. 用户可能正在同步编辑时，写入前再次读取目标段落；发现变化就停止覆盖，以新文本重新确定本节方案。

## 收尾

完成当前章节后再进入下一项。涉及术语、机制、结构、数字或图片的实质改动，仍按主流程记录影响并在收尾运行 R7；本文件不要求每节重复全篇审查。
