# 实质改动的影响记录

术语、机制、数字、范围、标题、章节顺序或图片发生变化时，在执行前记录本轮影响范围；纯标点或单句微调不需要创建本文件。

存储路径：`{项目根目录}/wenqu-skills/{文件名}/references/change-impact.md`。

## 格式

```markdown
# 变更影响记录

## 2026-07-25：本轮主题
- 改动：将“旧说法”改为“新说法”
- 影响对象：术语 / 机制边界 / 数字 / 标题 / 章节顺序 / 图片
- 不变边界：本轮不改哪些逻辑或章节
- 待检查：前后过渡、标题、表格、列表、总结、案例、图文、交叉引用
- R7：待检查 / 已闭环
```

## 规则

- 只记录实质改动；一轮多个紧密关联的改动可合并为一个条目。
- 执行前先写“改动、影响对象、不变边界”，避免顺手扩大修改范围。
- R7 完成后，将对应条目标记为“已闭环”，并在一行内说明检查过哪些地方。
- 不删除旧条目；它是 R7 在跨会话时追溯改动来源的首选依据。
