# 文章生命周期状态

`references/status.md` 是单篇文章跨会话的进度面板：只记录当前状态、下一步和待复查项，不重复 `materials/index.md`、`skeleton.md`、`changelog.md` 的内容。

## 何时创建与更新

- 新建文章存储时创建；已有文章首次按新流程续写时补建。
- 素材、骨架、章节、图片、审查或发布状态变化后更新对应行。
- 文章处于“待用户确认”时写清待确认对象；不要擅自标记完成。

## 模板

```markdown
# 文章状态

| 维度 | 当前状态 | 下一步 / 待复查 |
| --- | --- | --- |
| 素材 | 已收集 / 待补充 / 已裁决 | M12 的评测条件待核实 |
| 骨架 | 未开始 / 待确认 / 已确认 | 3.2 的范围待用户确认 |
| 章节 | 进行中 / 已确认 | 第四章已确认，第五章待写 |
| 图片 | 无需配图 / 待生成 / 已采用 / 待复查 | 4.2 图因正文变更待确认是否重画 |
| 审查 | 未开始 / 局部完成 / 完整通过 | R7 待本轮实质改动收尾后执行 |
| 发布 | 草稿中 / 待发布检查 / 已生成发布版 | 简介与封面待确认 |

## 本轮下一步

- [ ] …
```

## 反向验收

- **一节完成：** 读者能复述本节的核心判断，并知道它为何引向下一节。
- **一张图采用：** 只看图也能理解它承担的 1～2 个关键关系；图文术语、箭头、版本地址一致。
- **一轮修改完成：** 改动清单已逐项落地，R7 未发现旧术语、旧结论、旧图示或过期状态。
- **全文可发布：** 写作画像、骨架、正文、图片、评测叙事和审查结果之间没有冲突。
